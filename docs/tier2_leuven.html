Downtime for Lustre maintenance

Start: 2026-09-28 09:00:00
End: 2026-09-28 17:00:00
Updated: 2026-09-11 14:16:20
Level: high

Downtime is needed to perform maintenance on the Lustre filesystem. Lustre scratch and project storage will then be unavailable on all compute and login nodes.

For this purpose, the Genius and wICE clusters will be reserved for a full day, though we hope to release the reservation earlier if possible.

The Mindwell cluster will remain available during this maintenance, but Mindwell jobs will only get to start if you select the `no-lustre` reservation for the job. Please make sure to only do this for jobs which don't need to access the Lustre filesystem (otherwise these jobs will hang or crash while Lustre is unavailable).

You can select the `no-lustre` reservation by using the `--reservation=no-lustre` option for sbatch or srun. If needed, you can also let previously submitted jobs use the reservation by executing `scontrol -M mindwell update job reservation=no-lustre` for each job.

Downtime for Genius GPU migration

Start: 2026-09-28 09:00:00
End: 2026-09-30 17:00:00
Updated: 2026-09-23 13:39:50
Level: medium

For a more efficient organization of the data center, the Genius GPU nodes need to be migrated to wICE. For this we foresee a three-day downtime during which these P100 and V100 GPU nodes will be unavailable.

After the downtime, the Genius GPU nodes will be available on wICE. You will then need to submit your P100 and V100 GPU jobs to wICE instead of Genius. Genius jobs that are still pending when the maintenance starts will be modified to run on wICE.

After the downtime, wICE will furthermore replace Genius as the default Slurm cluster on the login nodes. This mainly implies that commands like `scontrol`, `squeue` and `scancel` will involve the wICE cluster if the `-M/--clusters` option is not used.
